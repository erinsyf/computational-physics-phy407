# Fourier Analysis and Optics

Python implementations of Fourier analysis techniques developed during PHY407 (Computational Physics) at the University of Toronto.

## Projects

### 1. Fourier Optics and Diffraction — Lab 05, Question 1b

**File:** `lab05_q1b.py`

Uses Fast Fourier Transforms (FFT) to calculate the diffraction intensity pattern produced by an optical grating.

### 2. Image Deblurring — Lab 05, Question 4

**File:** `lab05_q4.py`

Uses two-dimensional Fourier transforms to reconstruct an image blurred by a Gaussian point-spread function.

**Required dataset:** `blur.txt`

The dataset is provided in Mark Newman's *Computational Physics* online resources

Download `blur.txt` from the Chapter 7 section and place it in the working directory before running the script.

## Requirements

- Python 3
- NumPy
- SciPy
- Matplotlib
